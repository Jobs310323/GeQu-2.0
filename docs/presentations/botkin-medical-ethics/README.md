# Шесть принципов врачебной этики Е. С. Боткина

Учебная презентация (18 слайдов, .pptx) с заметками докладчика на каждом слайде.
Не связана с приложением GeQu — размещена здесь по запросу заказчика в рамках
этой сессии Claude Code.

## Ограничение по изображениям

В песочнице этой сессии сетевой доступ к внешним сайтам и медиа-хостингам
(Wikimedia Commons, архивы и т. д.) заблокирован политикой окружения — были
доступны только текстовые результаты веб-поиска. Поэтому в презентации нет
встроенных реальных исторических фотографий: на трёх слайдах, где фотография
важнее всего (титульный слайд, слайд 2 «Кто такой Боткин», слайд 12 «Тобольск —
Екатеринбург»), оставлены подписанные рамки-плейсхолдеры с описанием, какое
именно изображение туда нужно вставить. Остальные слайды используют графический
редакторский стиль (таймлайны, карточки, диаграммы) вместо фотографий.

## Фактчекинг

Все исторические факты и цитаты перепроверены через несколько независимых
источников (см. слайды 17–18 «Источники» внутри презентации). Формулировка
«шесть принципов» подана как современная реконструкция исследователей, а не
как документ, написанный самим Боткиным — это отдельно объясняется на слайде 4.
